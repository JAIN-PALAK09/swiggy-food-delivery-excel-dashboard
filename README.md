# Swiggy Food Delivery Analytics Dashboard

## 📊 Project Overview

This project is an interactive Food Delivery Analytics Dashboard created using Microsoft Excel.

The dashboard provides insights into orders, revenue, customers, payment methods, food categories, restaurants, and delivery performance.

## 🎯 Business Objectives

- Track overall order and revenue performance
- Analyze customer segments
- Understand order status and cancellation trends
- Identify top-performing restaurants
- Analyze revenue across cities and food categories
- Understand payment method usage
- Monitor average delivery time
